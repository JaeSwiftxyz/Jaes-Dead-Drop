# Changelog

## 1.0.0

* First public release.
* Zero-knowledge pastes: AES-256-GCM in the browser, key in the URL fragment.
* Passwords, burn-after-reading, expiration, discussions, attachments.
* Dark lime theme with a light counterpart; dark is the default.
* Subpath deployments, configurable sharing card, instance name and templates.
* Social cards ship canonical, OpenGraph URL/type and large image metadata; an
  off-site card URL is allowed through the image policy.
* File, database, S3 and Google Cloud storage backends.
